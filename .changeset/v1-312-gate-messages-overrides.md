Gate messages and recorded overrides (FR-GATE-8, FR-DEC-4). Core adds `formatGateMessage` and `confidenceBand`, which render one line per gate result with the reason, a `high`/`medium`/`low` confidence band and an override hint (`maina allow <decision-id> [--always]`). `evaluateGate` results now report `confidence`, the lowest confidence among the model's `action.risk` answers. Core also adds `recordOverride`, which links an `override` outcome to a logged decision, and `gateSubject`/`recordGateSubject`/`findGateSubject` with the `gate_subject` table (`migrateGateSubjects`), which keep a local record of what each decision was about. `scopedAllowRules` and `rememberOverride` turn that record into exact, kind-scoped allow rules and merge them into the user policy (`~/.maina/policy.json`, backed up before the first write). `rememberOverride` never writes a repo policy, and it refuses irreversible actions, final denies, opaque commands and wildcard targets. Also new in core: `userPolicyFile`, `readUserPolicy`, `getDecisionDb` (`.maina/decisions.db`) and `toDbPort`. The CLI adds `maina allow <decision-id> [--always]`, and the resident gate now reads the user policy, so an override remembered with `--always` applies on the next event.
