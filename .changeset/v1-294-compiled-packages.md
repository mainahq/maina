Ship compiled JavaScript and a single version source (FR-INS-1, FR-INS-2). `@mainahq/core` and `@mainahq/mcp` now publish `dist/` (ESM + `.d.ts`) instead of raw TypeScript `src/`, with `main`/`types`/`exports` pointing at the build; deep imports into `src/` no longer resolve (`runWikiLint` is now exported from core instead). The `maina` bin is a compiled, Node-loadable bundle whose header runs it with Bun when it is on PATH, else Node >= 20, so `maina --version` and `--help` work without Bun. `VERSION`, exported from core and generated by `scripts/version-source.ts` from the changeset version, is the only place the CLI, MCP server (`serverInfo.version` was a hardcoded `0.1.0`) and telemetry read the version; cli, core, mcp and skills are now one `fixed` changesets group, and cli/mcp pin their `@mainahq/*` dependencies exactly so an install never pairs a CLI with a newer core. MCP host entries written by a stable CLI install spawn its runtime and entry by absolute path, so GUI-launched hosts no longer need bun on PATH (P2) and unreleased builds no longer write a registry pin that cannot resolve (P3).
