## Next release

### Breaking changes

- Move onboarding and host MCP config out of `@mainahq/core` into the CLI (FR-INS-5). _(@mainahq/cli, @mainahq/core)_
- One idempotent onboarding flow (FR-INS-4, FR-INS-5). _(@mainahq/cli, @mainahq/skills)_
- Verify engine takes an explicit repository root and an injected environment instead of reading `process.cwd()`/`process.env`. _(@mainahq/cli, @mainahq/core, @mainahq/mcp)_
- Context, AI, config, git, review and receipt modules take an explicit repository root and an injected `EnvPort` instead of reading `process.cwd()`/`process.env`. _(@mainahq/cli, @mainahq/core, @mainahq/mcp)_
- Telemetry, feedback and benchmark read their environment through an injected `EnvPort` instead of `process.env`. _(@mainahq/cli, @mainahq/core)_
- Ship compiled JavaScript and a single version source (FR-INS-1, FR-INS-2). _(@mainahq/cli, @mainahq/core, @mainahq/mcp)_
- Remove the Lighthouse and ZAP verify runners, which the pipeline never ran (ADR 0042). _(@mainahq/core)_
- Host config merging with correct targets (FR-INS-4, FR-INS-6; fixes P1, P8). _(@mainahq/cli, @mainahq/skills)_
- All telemetry is opt-in, crash reports included (FR-PRIV-1), and `maina privacy` prints what may be sent (FR-PRIV-3). _(@mainahq/cli, @mainahq/core)_
- MCP server v2 tool set (FR-MCP-1, FR-MCP-2, FR-MCP-4). _(@mainahq/cli, @mainahq/core, @mainahq/mcp)_
- Skills follow the Agent Skills spec and are rewritten around the v1 flows: `gate`, `verify`, `spec`, `triage` and `graph`. _(@mainahq/cli, @mainahq/skills)_
- The published `@mainahq/core` declarations no longer reference drizzle-orm, so a Node TypeScript project with `skipLibCheck: false` can typecheck against them. _(@mainahq/cli, @mainahq/core)_
- `CorePorts` gains a required `process: ProcessPort` member (`spawn(argv, \{ cwd, env?, timeoutMs? _(@mainahq/core)_
- Every child process in core now goes through `ProcessPort`. _(@mainahq/cli, @mainahq/core, @mainahq/mcp)_

### Features

- New `maina acp --agent <name>` runs maina as an ACP agent for editors such as Zed and JetBrains IDEs. _(@mainahq/cli)_
- New `maina run <task>` runs a coding agent on a task in its own worktree, inside maina's OS sandbox. _(@mainahq/cli, @mainahq/core)_
- Core gains the building blocks for independent review, holdout scenarios, stop outcomes, a repo brain and evidence passed by reference: _(@mainahq/core)_
- Agent status line: `maina statusline install|remove|preview`. _(@mainahq/cli)_
- Weekly digest: `maina digest [--week yyyy-ww] [--send] [--card-labels] [--json]`. _(@mainahq/cli, @mainahq/core)_
- Terminal notifications for agent hooks: when the gate asks about an agent's action, or verify on session stop finishes, maina raises a desktop notification in the terminal the agent runs in. _(@mainahq/cli)_
- Local-first retention measurement: agent session starts (Claude Code, Cursor, Codex), the status line, terminal notifications and the weekly digest are noted in `~/.maina/retention.jsonl` on this machine. _(@mainahq/cli, @mainahq/core)_
- `budget.dailyUsd` and `budget.perTaskUsd` are now enforced across calls. _(@mainahq/core, @mainahq/mcp)_
- Add the functional-core ports boundary: `CorePorts` (`fs`, `git`, `db`, `clock`, `logger`, `model`, `env`) and their typed errors are exported from `@mainahq/core`, with in-memory fakes in `ports/testing.ts`. _(@mainahq/core)_
- Validated config and policy schema (#293). _(@mainahq/core)_
- `maina doctor` v2 (FR-INS-6): doctor now launches every configured maina MCP entry exactly as configured, under the host's minimal GUI environment (the `PATH` a Dock-launched host gets, plus `HOME`), and checks the entry, that the command resolves, the MCP `initialize` handshake, and which maina version answered. _(@mainahq/cli)_
- Migration from 1.x (FR-INS-8). _(@mainahq/cli)_
- Typed `decide` interface with a heuristic backend (#302). _(@mainahq/core)_
- Add an append-only decision log. _(@mainahq/core)_
- Add outcome capture linked to logged decisions (FR-DEC-4). _(@mainahq/core)_
- Add shadow mode, the promotion report and the drift guard for `decide` backends (FR-DEC-2, FR-DEC-8). _(@mainahq/core)_
- Add the gate's normalised events, classifier and rules engine (`packages/core/src/gate`). _(@mainahq/core)_
- Add `evaluateGate(ports, event, policy)`, the gate evaluator: the rules engine, then `decide("action.risk")`, then the policy's confidence threshold. _(@mainahq/core)_
- The gate classifies a plain read inside the workspace (or a temp dir) as the new `fs.read` action class, allowed by default like `fs.write`. _(@mainahq/core)_
- Codex support for the action gate. _(@mainahq/cli)_
- Gate messages and recorded overrides (FR-GATE-8, FR-DEC-4). _(@mainahq/cli, @mainahq/core)_
- Session summary of gate and routing outcomes (FR-RET-2). _(@mainahq/core)_
- New parser layer for the code graph: `parseFile(path, content, lang?)` parses TypeScript, TSX, JavaScript (with JSX), Python, Go, Rust and Java in-process with tree-sitter compiled to WebAssembly (`@vscode/tree-sitter-wasm`, no native build or external runtime; see ADR 0046). _(@mainahq/core)_
- New incremental code-graph store: `indexRepo(ports, root)` indexes every file a grammar reads (as git lists them, or by walking the tree outside a repository) and `updateFiles(ports, root, paths)` brings just the given paths up to date. _(@mainahq/core)_
- New code-graph queries over the incremental store. _(@mainahq/core)_
- The context engine's semantic layer now reads the code graph instead of regex-parsing imports (FR-GRAPH-5). _(@mainahq/core)_
- `maina verify` now checks the whole working tree by default: staged, unstaged and untracked changes against the base branch, so an unsaved-to-index edit with a finding is reported instead of passing silently. _(@mainahq/cli, @mainahq/core, @mainahq/mcp)_
- verify: findings and the review are now triaged through `decide` (#329). _(@mainahq/cli, @mainahq/core)_
- verify: type and test checks now cover the change's blast radius, read from the code graph (#330). _(@mainahq/cli, @mainahq/core)_
- Spec workflow upgrade. _(@mainahq/core)_
- Spec Kit interop. _(@mainahq/cli, @mainahq/core)_
- Model routing now comes from the `task.tier` decision with its confidence: an easy task keeps the cheaper tier when the decision is at or above the policy threshold, an uncertain one goes to the top tier. _(@mainahq/core)_
- MCP prompts (FR-MCP-3): the server now serves three prompts. _(@mainahq/mcp)_
- PR receipt check run and sticky comment v2 (#348). _(@mainahq/cli, @mainahq/core)_
- Teammate discovery from PRs and repo policy (#349, FR-RET-4). _(@mainahq/cli, @mainahq/core)_
- A `maina.config.ts` (or `.js`) with one invalid or unknown key no longer resets the whole config to the defaults. _(@mainahq/cli, @mainahq/core)_
- Decision log privacy: input, schema and option hashes can now be keyed by a per-repo random salt (`loadLogSalt`, stored in `.maina/private/log-salt`, which ignores itself in git and is never shared), so a list of repo files no longer reveals which path a hash stands for. _(@mainahq/core)_
- An agent can no longer override its own gate. _(@mainahq/cli, @mainahq/core)_
- Every gate ask or deny now has an override id that `maina allow` can resolve. _(@mainahq/core)_
- Policy rules take an optional `exact: true` (in the schema and the generated `schemas/policy.schema.json`): an exact rule matches the whole command, path, URL or `server/tool` name literally, with no `*` globbing, no basename, host or bare tool name match and, for a shell rule, no extra arguments. _(@mainahq/cli, @mainahq/core)_
- `evaluateGate` now returns `decided` when an `action.risk` decision was made. _(@mainahq/core)_
- A repo can now protect its own branches. _(@mainahq/core)_
- Agent files, skills and docs now name the v1 MCP tools (#465). _(@mainahq/cli, @mainahq/mcp, @mainahq/skills)_
- Every gate evaluation is now logged, allows included. _(@mainahq/core)_
- The gate now closes more ways an agent could turn off its own gate. _(@mainahq/core)_

### Fixes

- `DECISION_BACKENDS` (`rules`, `heuristic`, `system1`) is exported from the policy schema, so the docs checks read the backend list from the code instead of repeating it. _(@mainahq/core)_
- `maina verify` no longer reports inline type imports (`import { A, type B } from "…"`) as unused; the built-in unused-import check now strips the `type` modifier before looking for usages. _(@mainahq/core)_
- `maina verify` no longer runs code-pattern checks on data and docs files. _(@mainahq/core)_
- verify: built-in typecheck runs `tsc -p` per nearest tsconfig of the changed files instead of one root `tsc`, so workspace packages' own types and dependencies resolve (no more false TS2307/TS2868 on new package files). _(@mainahq/core)_
- `maina wiki compile` now prunes articles for deleted source files. _(@mainahq/core)_
- The built-in `no-console-log` check no longer reports `console.*` calls in dev-only tooling at the repo root (`scripts/`, `ci/`), matching the Biome `noConsole` override. _(@mainahq/core)_
- verify: the semgrep, trivy, secretlint, sonar-scanner, stryker and diff-cover runners now run the tool path that detection found, including a copy installed only in `<root>/node_modules/.bin`. _(@mainahq/cli, @mainahq/core)_
- The built-in hardcoded-secret check now catches JSON and YAML key forms. _(@mainahq/core)_
- Two verify false positives are fixed. _(@mainahq/cli, @mainahq/core)_
- The slop detector's `slop/hallucinated-import` rule no longer reads import-like text inside comments or string literals as an import. _(@mainahq/core)_
- The built-in `no-any-type` and `todo-comment` verify checks no longer flag text that only mentions their patterns. _(@mainahq/core)_
- Context commands that use the episodic layer (such as `review` and `verify`) no longer hang for about 43 seconds when maina cloud is slow or unreachable. _(@mainahq/core)_
- The built-in `no-any-type` check no longer flags identifiers that end in `any` when they are followed by punctuation, such as `many)`, `company,` or `Array<Company>`. _(@mainahq/core)_
- Add golden fixtures that pin the current output of every heuristic decision site (plan checklist, cross-artifact analyzer, spec quality, two-stage review, external-review categorisation, false-positive preferences, slop detector, AI output validation, wiki consult, relevance scoring, model tiers). _(@mainahq/core)_
- Export the gate verdict catalog (`VERDICTS`, `Verdict`) from the package root, so the resident runtime (#297) validates `allow | ask | deny` against the same list as the policy schema instead of redefining it. _(@mainahq/core)_
- MCP error isolation and real version (FR-MCP-5): a tool whose capability throws (or rejects) now answers with a structured `{ data: null, error: { kind: "failed", message }, meta }` result instead of an unstructured SDK error, and the server keeps serving the next call. _(@mainahq/mcp)_
- MCP roots and a single server per process (FR-INS-3). _(@mainahq/mcp)_
- Host config edits fail closed on a wrong-typed container (#384). _(@mainahq/cli)_
- `maina setup` no longer makes the constitution AI call (host, cloud or BYOK) when `.maina/constitution.md` already exists. _(@mainahq/cli)_
- The verify line lexer now models template literal interpolations. _(@mainahq/core)_
- `maina doctor` no longer launches a project-scope `bunx`/`npx @mainahq/cli@X --mcp` entry when the repo ships its own `node_modules/@mainahq/cli` or a project `.npmrc` (in the working directory or any directory up to the repo root): npx resolves a matching local copy in place of the published package, and honours a project `.npmrc` `registry=`, so that entry could run code the repo chose. _(@mainahq/cli)_
- Overlapping code-graph syncs no longer let a stale plan overwrite newer work (FR-GRAPH-2). _(@mainahq/core)_
- `maina setup` now writes package-manager-specific commands into AGENTS.md. _(@mainahq/cli)_
- `maina doctor` no longer runs a repo's `bunfig.toml` preload when it launches a configured MCP entry on its own. _(@mainahq/cli)_
- `gate.self_override` now matches gate control files and directories in any letter case. _(@mainahq/core)_
- Gate: a write or delete whose target the shell walk cannot resolve now classifies as `shell.opaque`, so the default policy asks (FR-GATE-2, FR-GATE-4). _(@mainahq/core)_
