Every key `maina.config.*` accepts, read from the zod schema that also generates `schemas/maina.config.schema.json`. Every key is optional.

| Key | Type | Description |
|---|---|---|
| `models` | object |  |
| `models.mechanical` | string | Cheap, fast tier: commit messages, tests, slop detection, compression. |
| `models.standard` | string | Mid tier: reviews, plans, design docs. |
| `models.architectural` | string | Top tier: design review, architecture, prompt evolution, and any task routing is unsure about. |
| `provider` | string | AI provider: openrouter, anthropic, ... |
| `budget` | object |  |
| `budget.dailyUsd` | number (at least 0) or null | Spend cap per UTC day in US dollars. null disables the cap. |
| `budget.perTaskUsd` | number (at least 0) or null | Spend cap for a single command in US dollars. null disables the cap. |
| `budget.onBreach` | `degrade` or `stop` | What happens when a cap is reached: degrade to the lower tier, or stop with a message. |
| `repoAliases` | map of string | Short names for GitHub repositories, used by `maina ticket`. |
| `telemetry` | boolean | 1.x setup telemetry opt-out (false opts out). Superseded by policy.telemetry. |
| `digest` | object | Where `maina digest --send` delivers the weekly card. Nothing is sent unless a channel is set here. |
| `digest.webhook` | object |  |
| `digest.webhook.url` | string | Incoming webhook that receives \{ "text": &lt;card&gt; \} (Slack, Mattermost, ...). |
| `digest.email` | object | Mail the card through the local `sendmail -t`. |
| `digest.email.to` | array of string | Recipients of the card. |
| `digest.email.from` | string | Sender address; the local user when absent. |
