Every key a policy file (`.maina/policy.json` in a repo, `~/.maina/policy.json` for the user) accepts, read from the zod schema that also generates `schemas/policy.schema.json`. Layers merge in the order defaults, user, repo.

| Key | Type | Description |
|---|---|---|
| `version` | `1` |  |
| `explicitly_allow` | array of string | Irreversible action classes this layer is allowed to loosen. Anything else it tries to loosen is an error. gate.self_override can never be listed. |
| `action_classes` | map of object |  |
| `action_classes.<name>.irreversible` | boolean | Irreversible classes can be tightened by any layer but loosened only when the layer lists them in explicitly_allow. |
| `action_classes.<name>.verdict` | `allow` or `ask` or `deny` | Gate outcome when an action falls in this class. |
| `rules` | object | Rule lists accumulate across layers; none can be removed. |
| `rules.allow` | array of object |  |
| `rules.allow[].match` | string | Command, path glob or tool name. |
| `rules.allow[].kind` | `shell` or `file.write` or `file.read.outside` or `mcp` or `network` | Event kind the rule applies to; every kind when omitted. |
| `rules.allow[].exact` | boolean | Match the whole command, path, URL or server/tool name literally: no `*` globbing, no basename, host or bare tool name match and, for a shell rule, no extra arguments. `maina allow --always` writes exact rules. |
| `rules.allow[].reason` | string |  |
| `rules.deny` | array of object |  |
| `rules.deny[].match` | string | Command, path glob or tool name. |
| `rules.deny[].kind` | `shell` or `file.write` or `file.read.outside` or `mcp` or `network` | Event kind the rule applies to; every kind when omitted. |
| `rules.deny[].exact` | boolean | Match the whole command, path, URL or server/tool name literally: no `*` globbing, no basename, host or bare tool name match and, for a shell rule, no extra arguments. `maina allow --always` writes exact rules. |
| `rules.deny[].reason` | string |  |
| `protected_branches` | array of string | Branches a plain push to asks (git.push.protected) and a lease or delete push to counts as a force push (git.push.force). Lists accumulate across layers on top of main and master; none can be removed. |
| `decisions` | map of object |  |
| `decisions.<type>.backend` | `rules` or `heuristic` or `system1` |  |
| `decisions.<type>.thresholds` | object |  |
| `decisions.<type>.thresholds.confidence` | number (0 to 1) | Minimum confidence at which the backend's answer is acted on. |
| `decisions.<type>.error_costs` | object |  |
| `decisions.<type>.error_costs.false_positive` | number (at least 0) |  |
| `decisions.<type>.error_costs.false_negative` | number (at least 0) |  |
| `drift` | object |  |
| `drift.window` | integer | Number of recent decisions the drift guard looks at. |
| `drift.max_error_rate` | number (0 to 1) | Error rate above which a decision type is demoted. |
| `drift.max_confidence_drop` | number (0 to 1) | Drop in mean confidence above which a decision type is demoted. |
| `telemetry` | object | Opt-ins. Only the user policy can turn one on. |
| `telemetry.crash_reports` | boolean |  |
| `telemetry.usage` | boolean |  |
| `telemetry.outcome_sharing` | boolean |  |
| `log` | object | What the local decision log keeps in the clear. |
| `log.paths` | `hashed` or `plain` | hashed (default): the decision log stores paths and other free-form options only as hashes keyed by a per-repo salt. plain: stores them as-is. |
| `run` | object | Per run context (maina run): classes it never performs and the budgets it stops at. |
| `run.interactive` | object |  |
| `run.interactive.deny` | array of string | Action classes a run in this context never performs, whatever their verdict. Lists accumulate across layers; none can be removed. |
| `run.interactive.budgets` | object | A run in this context stops, with a report, at the first budget it breaches. A repo policy can only lower a budget. |
| `run.interactive.budgets.wall_clock_minutes` | number | Longest a run may take, from its first agent turn to its last review. Unset means unlimited. |
| `run.interactive.budgets.max_tool_calls` | integer | Tool calls a run may make across all its attempts; the next one stops it. Unset means unlimited. |
| `run.unattended` | object |  |

| `run.unattended.budgets.max_tool_calls` | integer | Tool calls a run may make across all its attempts; the next one stops it. Unset means unlimited. |
| `discovery` | object | How teammates who do not use Maina find it (FR-RET-4). |
| `discovery.receipt_line` | boolean | Show the one-line Maina footer on PR receipt comments (default true). `maina receipt publish` reads it from the repo policy. |
