Every decision type `decide` answers (the `decide` MCP tool and `maina decide`), read from the decision catalog. The policy's `decisions` key picks a type's backend and thresholds; the default backend serves it otherwise.

| Type | Question | Question kinds | Options | Default backend |
|---|---|---|---|---|
| `action.risk` | Is this agent action allowed, asked about or denied? | `choice` | `allow`, `ask`, `deny` | `rules` |
| `diff.sensitive` | Does this diff touch security-sensitive code? | `bool` | any | `heuristic` |
| `diff.needs_review` | Does this diff need a deep review? | `bool` | any | `heuristic` |
| `task.tier` | Which model tier should run this task? | `choice` | `mechanical`, `standard`, `architectural` | `heuristic` |
| `finding.real` | Is this finding (or finding rule) a real problem? | `bool` | any | `heuristic` |
| `finding.severity` | How severe is this finding? | `choice` | `error`, `warning`, `info` | `heuristic` |
| `spec.coverage` | Is this requirement or task covered? | `bool` | any | `heuristic` |
| `spec.orphan` | Does this task or change map to no requirement? | `bool` | any | `heuristic` |
| `spec.contradiction` | Do these two artifacts contradict each other? | `bool` | any | `heuristic` |
| `spec.impl_leak` | Does this line mix WHAT/WHY and HOW across spec and plan? | `bool` | any | `heuristic` |
| `spec.quality` | How measurable, testable, unambiguous and complete is it? | `score` | any | `heuristic` |
| `review.category` | Which category does this review comment belong to? | `choice` | `api-mismatch`, `signature-drift`, `dead-code`, `security`, `style`, `other` | `heuristic` |
| `review.reviewer_kind` | Is this reviewer a bot or a human? | `choice` | `bot`, `human` | `heuristic` |
| `slop` | Is this code or text an AI-slop pattern? | `bool` | any | `heuristic` |
| `wiki.relevance` | Is this wiki article relevant to the query? | `bool` | any | `heuristic` |
| `context.select` | How relevant is this file to the current task? | `score`, `choice` | any | `heuristic` |
