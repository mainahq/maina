The lifecycle points maina hooks, and the native hook each host registers for them, read from the host adapters' hook maps. A blocking hook gates an action, so when it crashes or times out the action is blocked (fail closed).

## Lifecycle events

| Event | What maina does | Blocking |
|---|---|---|
| `session.start` | A session starts: maina adds its context. | no |
| `tool.before` | Before a tool runs: the gate decides allow, ask or deny. | yes |
| `permission.request` | The host is about to prompt for a permission: the gate decides. | yes |
| `file.edited` | After a file edit: the code graph observes it. | no |
| `session.stop` | The agent stops: maina verifies the session's changes. | no |
